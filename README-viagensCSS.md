# 🌍 Viagens CSS

Site informativo sobre destinos turísticos internacionais, desenvolvido para praticar a construção e a estilização de páginas web com **HTML**, **CSS** e **Flexbox**.

## ✨ Sobre o projeto

O **Viagens CSS** convida o visitante a explorar diferentes lugares do mundo. Na página inicial, é possível selecionar um destino e acessar conteúdos relacionados à sua cultura e aos seus atrativos turísticos.

Os destinos apresentados são:

- 🇬🇷 **Atenas, Grécia**
- 🇨🇭 **Lauterbrunnen, Suíça**
- 🇳🇴 **Tromsø, Noruega**
- 🇨🇳 **Xangai, China**
- 🇯🇵 **Yokohama, Japão**

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas.
- **CSS3:** aparência, cores e organização visual.
- **Flexbox:** distribuição e alinhamento dos elementos na interface.

## 📁 Estrutura do repositório

```text
viagensCSS/
├── .vscode/
├── CSS/
├── HTML/
├── imagensMBC/
├── Index.css
├── index.html
└── README.md
```

O arquivo `index.html` é a página inicial; as pastas `HTML/`, `CSS/` e `imagensMBC/` reúnem páginas, estilos e recursos visuais do projeto.

## 🚀 Como visualizar

Acesse a versão publicada: **[Viagens CSS na Vercel](https://viagens-css.vercel.app/)**.

Para executar localmente:

1. Clone o repositório:
   ```bash
   git clone https://github.com/MelissaCrepaldi/viagensCSS.git
   ```
2. Abra a pasta `viagensCSS`.
3. Abra o arquivo `index.html` no navegador.
